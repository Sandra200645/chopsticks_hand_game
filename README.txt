CHOPSTICKS - VERTICAL VERSION

Changes:
- Uses local cartoon hand drawings inspired by the hand reference supplied by the user.
- No internet is required for the hand images.
- Portrait/vertical layout.
- Player 1 on the left and Player 2 on the right, with two hands stacked, matching the sketch arrangement.
- OUT hands disappear instead of showing a fist or zero hand.
- Game logic uses wrap-around:
  4 + 2 = 6 -> 1
  4 + 4 = 8 -> 3
  3 + 2 = 5 -> OUT
- SPLIT:
  2 + 0 -> 1 + 1
  4 + 0 -> 2 + 2
- When both hands of one player are OUT, the other player wins.

How to run:
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open index.html using Live Server.
